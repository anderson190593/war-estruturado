# war-estruturado
Projeto desenvolvido em linguagem C como parte de um curso de estrutura de dados. Simula uma versão simplificada do jogo War, com cadastro de territórios, sistema de ataque entre exércitos e atribuição dinâmica de missões estratégicas. O código utiliza structs, ponteiros, alocação dinâmica de memória, modularização e lógica condicional para representar a mecânica básica do jogo.
